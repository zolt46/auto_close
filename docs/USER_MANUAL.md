# 사용자 매뉴얼 (EXE 운영 기준)

이 문서는 `AutoCloseStudio.exe`를 현장에서 운영하는 사용자를 위한 실무 절차서입니다.

---

## 1. 프로그램 목적

AutoClose Studio는 지정된 요일/시간에 아래 작업을 자동 실행합니다.

1. 실행 중인 특정 프로그램 종료
2. 안내 음원 재생
3. 원격 PC 종료(선택)
4. 현재 PC 종료(선택)

---

## 2. 최초 실행

1. `AutoCloseStudio.exe` 실행
2. 트레이 아이콘이 생성됨(창이 바로 안 보일 수 있음)
3. 트레이 메뉴에서 **열기** 선택
4. 일반 사용자 비밀번호 입력
   - 기본값: `0000`

> 보안상, 운영 시작 전에 반드시 비밀번호를 변경하세요.

---

## 3. 화면/메뉴 구성

주요 화면:
- 홈(오늘 일정, 다음 실행 예정, 즉시 실행)
- 요일 일정
- 플레이리스트
- (관리자 로그인 후) 휴일
- (관리자 로그인 후) 고급 설정

트레이 메뉴(대표):
- 열기/숨기기
- 도움말
- 종료

---

## 4. 기본 운영 절차

## 4.1 요일별 스케줄 설정

1. **요일 일정** 화면 진입
2. 각 요일별로:
   - 사용 여부(ON/OFF)
   - 실행 시간(HH:MM)
   - 자동 음원 할당 또는 수동 음원 선택
   - 원격/로컬 종료 허용 여부
3. 저장(대부분 변경 즉시 반영)

## 4.2 플레이리스트 설정

1. **플레이리스트** 화면 진입
2. 음원 파일 추가/삭제
3. 자동 할당 미리보기 확인

자동 할당 ON인 요일은 플레이리스트 순환 규칙에 따라 음원이 배정됩니다.

## 4.3 테스트 실행(권장)

1. 홈 화면에서 **지금 즉시 실행** 사용
2. 아래 순서 정상 확인
   - 프로그램 종료
   - 음원 재생
   - (옵션) 원격 종료
   - (옵션) 로컬 종료

운영 투입 전 테스트를 반드시 1회 이상 진행하세요.

---

## 5. 관리자 기능

## 5.1 관리자 모드 진입

- 상단 제목을 연속 클릭(앱 내 안내 방식)하여 로그인 창 호출
- 관리자 비밀번호 입력
  - 기본값: `000000`

## 5.2 휴일 관리

- 단일 날짜 추가
- 기간(시작~종료) 추가
- 목록 삭제
- 휴일일 때 종료 정책(원격/로컬) 분리 적용

## 5.3 고급 설정

- 일반/관리자 비밀번호 변경
- 원격 호스트 목록 관리
  - 방법: `winrm` 또는 `ssh`
- 시작 프로그램 등록 여부
- 테마/저장 위치 변경 등

---

## 6. EXE 운영 시 주의 사항

- 트레이 기반 프로그램이므로 창을 닫아도 백그라운드 실행될 수 있습니다.
- 로컬 종료 기능을 켜면 실제 PC가 종료되므로 테스트 시 지연시간을 충분히 설정하세요.
- 원격 종료는 네트워크/계정 권한 문제로 실패할 수 있습니다.
- 운영 정책에 따라 백신 예외/코드서명 적용을 검토하세요.

---

## 7. 장애 대응 가이드

## 7.1 음원이 재생되지 않음

점검:
- 파일 경로 유효한지
- 파일이 삭제/이동되지 않았는지
- 오디오 장치 연결 상태

## 7.2 원격 종료가 동작하지 않음

점검:
- 대상 호스트 주소, 계정, 비밀번호
- SSH 키 경로 설정
- 방화벽/망 접근 허용
- 대상 PC의 원격 종료 명령 허용 정책

## 7.3 앱이 보이지 않음

점검:
- 트레이 아이콘 확인
- 트레이 메뉴의 **열기**로 진입
- 다중 실행 방지 로직으로 이미 실행 중일 수 있음

## 7.4 설정이 반영되지 않음

점검:
- 저장 경로 변경 여부
- 설정 파일 쓰기 권한
- 앱 재시작 후 재검증

---

## 8. 운영 권장 시나리오

1. 관리자 모드로 비밀번호 변경
2. 종료 대상 프로그램/원격 호스트 등록
3. 요일별 시간표 + 플레이리스트 설정
4. 휴일 정책 등록
5. 즉시 실행 테스트
6. 시작 프로그램 등록 후 상시 운영
